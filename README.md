# Anita Pal Portfolio

A professional portfolio website for Anita Pal, designed for a Human Resource Professional profile.

## About

This portfolio highlights Anita Pal's HR experience, skills, tools, education, and contact details. The design is soft, modern, responsive, and includes dark/light theme functionality.

## Features

- Modern responsive UI
- Multi-page portfolio
- Dark and light theme
- Professional hero section with profile image
- About, Expertise, Experience, Contact pages
- Resume download option
- SEO metadata
- Sitemap and robots file
- Fast production build with Next.js

## Tech Stack

- Next.js
- React.js
- Tailwind CSS
- CSS animations
- Vercel ready
